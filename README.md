## 📁 目录结构 / Folder structure

```
original_screenshots/          原始整页截图/文档（未改动）/ untouched originals
    听力: listening1.jpeg listening2.jpeg   (Listening pages 1–2, 15 题/questions)
    阅读: reading1.jpeg reading2.jpeg        (Reading   pages 1–2, 16 题/questions)
    口语: speaking1.jpeg speaking2.jpeg speaking3.jpeg  (Speaking pages 1–3, 30 题/questions)
    写作: writing1.jpeg                      (Writing  page 1, 4 题/questions)
    listening.docx / speaking.docx / writing.docx
        — 平台里额外截的「AI 评分」弹窗（每题的详细评分/带色标改错），
          逐题裁剪时已拆出白色弹窗部分挂到对应题目，见下方「xxb」文件。
        — Supplementary "AI scoring" popup screenshots (per-question detailed
          rubric / color-coded corrections) the platform only shows on click;
          the white modal was cropped out of each and attached to its question
          as the "xxb" file below.

cropped_questions/             逐题裁剪成品（要交付的）/ per-question crops (the deliverable)
    listening/   15 题 + 1 张 SST AI 评分详情 (L01b)      = 16 files
    reading/     16 题                                    = 16 files
    speaking/    30 题 + 24 张 AI 评分详情 (RA/RS/DI/RTS)  = 54 files
    writing/     4 题 + 4 张 AI 评分详情                   = 8 files
```

**命名规则 / Naming:** `前缀+序号[b]_题型_题库编号[_标题].png`
`L`=Listening, `R`=Reading, `S`=Speaking, `W`=Writing；序号两位补零，跨图连续编号；
`b` 后缀 = 该题的补充「AI 评分详情」弹窗截图（来自 docx），紧跟在主图之后。

例 / e.g.: `L07_SMW_119_Forgiving.png`、`S19_DI_696_Trailing_Sails.png`、`S19b_DI_696_Trailing_Sails.png`（对应弹窗）。
