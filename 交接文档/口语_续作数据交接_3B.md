## 6. ⭐ ASR 逐词配色工具用法（`build/asr_classify.py`）

平台「AI 语音识别」逐词上色，本卷逐词复刻。**别肉眼一个个猜**——用工具批量分类，再肉眼抽查：

```bash
# 1) 先肉眼看 S##b 图，把 ASR 那段文字按顺序抄成一个字符串（含口误/重复词，照原样）
# 2) 跑分类器，得到每个"词块"的颜色（green/orange/red/pause）：
python3 build/asr_classify.py cropped_questions/speaking/S02b_RA_763_Peptic_Ulcer.png <x0> <y0> <x1> <y1>
#    <x0 y0 x1 y1> 是 ASR 文字区域的像素框（先 pngcrop/Pillow 定位）。RA 的 b 图 ASR 区约在 y≈505–780(S01b那种半屏弹窗) 或 y≈925–1050(S02b那种整屏)；每张不同，先裁一小条看。
# 3) 或直接生成 LaTeX（把抄好的词串作为第 7 个参数传入，工具按颜色套 \sg/\sy/\sr，pause→\pse）：
python3 build/asr_to_latex.py <图> <x0> <y0> <x1> <y1> "word1 word2 word3 ..."
```

- 颜色→宏：green=`\sg`(优)、orange=`\sy`(良)、red=`\sr`(差)、pause=`\pse`(停顿)。RS 的红色**删除线**（漏读）在工具里也是 red，但要手动改成 `\smiss{}`（红删除线）而非 `\sr{}`——**RS 看是不是带删除线**：带删除线=漏读=`\smiss`，不带=正常上色。
- 工具会打印 `# entries / pause / words_given` 统计；**词数对不上就说明裁框漏了词或多了**，调框重跑。
- **务必肉眼抽查几处**（尤其橙/红边界、停顿位置），工具偶尔把浅红认成橙。参考 §1 Q1 已核对的串作为标准样例。
