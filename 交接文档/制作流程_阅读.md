## 1. 输入与题型

- **题目素材**：`cropped_questions/reading/R01`–`R16`——每张图从题号标题裁到评分行，含文章/填空作答/选项（或词库）/你的答案/评分，直接 `Read` 誊录即可。

PTE Core 阅读题型（3B 实际 16 题，与 2B 题型分布完全一致——PTE Core 阅读固定结构）：

| 题型 | 3B 数量 | 每题要素 |
|------|------|----------|
| **FIB**（下拉选词）| 5（Q1–5）| 文章（含填空作答）+ 每空 4 个选项 + 评分（分母 4 或 5，随题变化）|
| **MCM-R** 多选 | 2（Q6–7）| 文章 + 题目 + 选项 A–F + 正确/你的答案 + 评分（本套均 /2）|
| **RO** 段落重排 | 2（Q8–9）| 4 个乱序段落 + 正确顺序 + 你的顺序 + 评分（分母 3，非题数）|
| **FIBD\&D**（拖词入空）| 5（Q10–14）| 文章（含填空）+ 词库（词数多于空格）+ 评分（分母 4）|
| **MCS-R** 单选 | 2（Q15–16）| 文章 + 题目 + 选项 + 正确/你的答案 + 评分（均 /1）|

每空 / 每选项：平台用 **✓ 绿（对）/ ✗ 红（错，后跟正确答案）**，与听力/2B 阅读完全一致，复用 `\rok`/`\rno`。

## 2. ⭐ 填空 / 选择 答案标注（核心宏，与总册 §7 相同）

`ptestyle.sty` 里（需 `\usepackage{pifont}` 出 ✓✗）：

| 宏 | 含义 | 外观 |
|----|------|------|
| `\rok{词}` | 选对 | 绿 ✓ + 词 |
| `\rno{你的}{正确}` | 选错 | 红 ✗ + 删除你的词 + `(答案: 正确)` |

**文章里每个空就地嵌 `\rok/\rno`**，例：`plants with \rno{artificial}{favorable} traits`。

- **未作答的空**：本套 Q12（India）第 2 空平台截图显示为空白下划线 + ✗（既没红字也没词），说明**根本没填**，
  用 `\rno{（未填）}{elaborate}` 表示（"未填"两字加删除线只是占位，别当成你真写了这个词）。
- **选项 Choices**：FIB 每空一行（4 词）、FIBD\&D 一个共享词库；正确项 `\textbf{加粗}`。
- **MCM/MCS**：选项 A–F 列出，正确项用 `{\color{cFix}\textbf{...}}`（绿粗）；
  答案行 `正确答案 \textcolor{cFix}{\bfseries B, C}\qquad 你的答案 {\color{cWrong}\bfseries C, F}`。

## 3. ⚠️ 解析（本套与 2B 不同——大多数题目没有解析文字可抄）

- 2B 那套阅读截图**每题解析都是直接展开显示的**，本套（3B）复盘页的解析是**点击「？」图标才展开的气泡**，
  截图时大多数题目这个气泡**没有点开**，所以本版本（`000`）**16 题里只有 Q13 有完整解析**，其余 15 题只保留
  文章/选项/答案，**没有编造解析**。
- 如果后续要补全解析：去平台该题逐空点开「？」气泡截图，或点「查看原题」，再补进对应 `\ptesub{解析 Explanation}` +
  `notebox`（格式照抄 Q13 的写法：`【思路】…` + 排除法 + 一句话总结 + `【解题思路：…】`标签）。
- **RO/MCM/MCS 本来就没有逐项解析**（只有正确答案 + 你的答案），这点与 2B 一致，不受此限制影响。

## 4. 翻译（每题都加）

`\zh{中文}` 给**每篇文章 / 每组段落**加整段翻译，放在 `promptbox` 正下方；RO 的翻译按**正确顺序**整段译出并注明"（按正确顺序）"。

## 5. 逐题 LaTeX 结构

**FIB 模板**（本套多数题无解析，故没有 `\ptesub{解析}` 段落，选项列表后直接接 `\par\smallskip` + 答案行）：

```latex
\begin{qblock}{Q1\quad FIB \#384\ \ Starvation}{读写填空 · 评分 \textcolor{cAccent}{\bfseries 3 / 5}}
\ptesub{文章 Passage（含填空作答）}
\begin{promptbox} …文章，空处 \rok{对} / \rno{你的}{正确}… \end{promptbox}
\zh{…整段翻译…}
\ptesub{选项 Choices（每空 4 选 1，正确项加粗）}
{\small 1.\ \textbf{a},\ b,\ c,\ d\\ 2.\ … }
\par\smallskip
\textbf{你的答案：}\ …\qquad\textbf{本题得分：}\ \textcolor{cAccent}{\bfseries 3 / 5}\quad{\footnotesize\color{gray}（…）}
\end{qblock}
```

> ⚠️ **别漏了 `\par\smallskip` 前的 `\par`**：如果选项列表（`{\small …}` 组）后面不是 `\end{notebox}` 之类的环境，
> 直接接 `\smallskip` **不会**自动断开段落，会导致「选项」和「你的答案」两行文字挤成一行（本轮排版踩过这个坑，
> 编译后渲图核对发现的）。只要选项/词库列表和答案行之间没有 `notebox` 等环境隔开，**必须**手动加 `\par`。

- **MCM / MCS**：`promptbox` 文章 + `\zh` + `\ptesub{题目}`（`notebox`）+ `\ptesub{选项 Choices}`（A–F，正确项绿粗）+ `\par\smallskip` + 答案行。
- **RO**：`promptbox` 内 4 段，每段 `\textbf{1)}…`；`\zh` 翻译（按正确顺序）；`\par\smallskip` + 末尾 `正确顺序 \textcolor{cFix}{\bfseries 1 → 4 → 2 → 3}\qquad 你的顺序 …`。
- **FIBD\&D**：词库写成一行 `1) 词\quad 2) \textbf{词}…`（正确答案加粗，其余是干扰词，不用管顺序）；有解析的题（本套仅 Q13）在词库后加 `\ptesub{解析 Explanation}` + `notebox`。
