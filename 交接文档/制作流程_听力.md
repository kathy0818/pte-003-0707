## 1. 输入与题型

- **题目素材**：`cropped_questions/listening/L01`–`L15`——每张图从题号标题裁到评分行，**已含录音播放器（无文字 Transcript，仅 SST 缺）/ Transcript / 你的作答 / 评分**，直接 `Read` 誊录即可。
- **⭐ SST 评分明细**：`L01b_SST_6_Democracy.png`——SST 的 **Content/Form/Grammar/Spelling/Vocabulary 五项打分 + AI 建议 + 你概述的错词彩色标注**（红/蓝色框 = 拼写错误/冗余词删除，与 `\fix`/`\del` 对应）。
- **SST 音频原文**：`L01` 图里只有播放器（0:00/0:00），**没有文字 Transcript**，需在平台点该题「查看原题」复制。

PTE Core 听力题型（3B 实际 15 题，与 2B 题型分布完全一致——PTE Core 听力固定结构）：

| 题型 | 3B 数量 | 每题要素 |
|------|------|----------|
| **SST** 概述口语 Summarize Spoken Text | 1（Q1）| （音频原文缺）+ 你的概述 + 五项评分明细（/10）|
| **MCM-L** 多选 | 1（Q2）| 录音原文 + 题目 + 选项 A–E + 正确/你的答案 + 评分（本套是 /3，非固定 /2）|
| **FIB-L** 听力填空（打字）| 3（Q3–5）| 录音原文（含填空作答 ✓/✗）+ 评分（无选项，打字题；空数随题变化 4/4/5）|
| **MCS-L** 单选 | 1（Q6）| 录音原文 + 题目 + 选项 + 正确/你的答案 + 评分 |
| **SMW** 选词 Select Missing Word | 2（Q7–8）| 录音原文（结尾词被「哔」替换）+ 选项 + 正确/你的 + 评分 |
| **HIW** 找错词 Highlight Incorrect Words | 3（Q9–11）| 录音原文（屏幕错词标出）+「实际读音」+ 你点了哪几个 + 评分（本套错词数 5/5/6，非固定）|
| **WFD** 听写 Write From Dictation | 4（Q12–15）| 正确句子 + 你的作答（逐词批改）+ 评分（本套 9/10/9/11，非固定）|

> ⚠️ **各题评分分母不是固定值**：MCM-L 本套是 `/3`（2B 是 `/2`）、HIW 各题应点错词数 5~6 个不等、
> WFD 各题满分 9~11 不等——**都以截图里 `评分详情 x/y分` 的实际 y 为准**，别套用别的套的分母。

## 2. ⭐ 听力专用宏（`ptestyle.sty`）—— 与总册 §7 相同，此处给用法提醒

| 宏 | 用于 | 外观 |
|----|------|------|
| `\rok{词}` / `\rno{你的}{正确}` | FIB-L 填空对错 | 同阅读（绿✓ / 红✗+答案）|
| `\hiw{屏幕错词}{实际读音}` | **HIW** | 屏幕错词**红下划线** + `(听:实际读音)` |
| `\lhit{词}` | **WFD** 命中 | 绿 |
| `\womit{词}` | **WFD** 漏写（本套配色）| **红色括号** `(词)` |
| `\wbad{词}` | **WFD** 多写/听错（本套配色）| **灰删除线** |
| `\wfdlegend` | WFD 一行图例 | 命中 / (漏写) / 多写听错 |

**HIW 原理**：屏幕上显示的文字与录音不符，要**点出与录音不同的词**。平台给：`答案: Pronounced words: …`（= 实际读音/正确词）。把屏幕错词逐个 `\hiw{屏幕}{读音}` 标进原文，再补一行汇总「应点的 N 个错词 / 你点了哪几个」。**注意映射顺序**：屏幕错词与正确读音是**按出现顺序一一对应**的（第 1 个错词对应答案里第 1 个读音，以此类推），不要凭词形相似度乱配对。

**WFD**：平台逐词批改——**绿=命中**、**(红括号)=漏写**、**灰删=多写或听错**。放大截图核对每个词的确切颜色/是否有括号/是否有删除线，逐词转成对应的宏，别凭大意归类。

## 3. 录音原文 & 翻译（每题都加）

- 录音原文（Transcript）直接照抄图里的文字（**注意是听力口语稿，可能有口误/不规范，照原样**）。SST 原文需「查看原题」另取，本套 `000` 暂缺并标红。
- `\zh{中文}` 给**每段录音原文 / 每个 WFD 句子**加翻译。
- SST 还要保留**你的概述**（含 AI 标注的待改词，拼写错误用 `\fix`、冗余词删除用 `\del`）+ 五项评分表。

## 4. 逐题 LaTeX 结构

- **SST**：`\ptesub{录音原文}` promptbox（本套标红说明缺失）→`\ptesub{你的概述}` youbox + `\zh` →`\ptesub{AI 评分明细}` notebox 内 `tabular`（Content/Form/Grammar/Spelling/Vocabulary 各一行 + 得分 + 建议）。
- **MCM-L / MCS-L**：`\ptesub{录音原文}` + `\zh` + `\ptesub{题目}` + `\ptesub{选项}`（正确绿粗）+ 答案行。
- **FIB-L**：`\ptesub{录音原文（含填空作答）}` promptbox（空用 `\rok/\rno`）+ `\zh` + 一行说明你的作答（打字题无选项）。
- **SMW**：录音原文结尾用 `\rule{1.2cm}{0.4pt}\ \textit{[beep]}` 表示被替换的词 + `\zh` + 选项 + 答案行。
- **HIW**：录音原文（`\hiw` 标错词）+ `\zh` + 一行「应点的 N 个错词 / 你点了…」。
- **WFD**：`\ptesub{正确句子}` promptbox + `\zh` + `\ptesub{你的作答（逐词批改）}\ \wfdlegend` + 逐词批改串。
- 标题右上放评分：`… · 评分 \textcolor{cAccent}{\bfseries 7 / 10}`。

| Q6 | MCS-L \#125 | Jobs | 1/1 | Q14 | WFD \#1929 | Several major companies and organizations… | 7/9 |
| Q7 | SMW \#119 | Forgiving | 0/1 | Q15 | WFD \#1926 | Graduates have to fight for jobs… | 7/11 |
| Q8 | SMW \#113 | Great Conversation | 0/1 | | | | |

- 题型构成：**SST×1（Q1）· MCM-L×1（Q2）· FIB-L×3（Q3–5）· MCS-L×1（Q6）· SMW×2（Q7–8）· HIW×3（Q9–11）· WFD×4（Q12–15）**，共 15 题，听力 **55/90**。
- **SST(Q1)**：录音原文未给（需「查看原题」），`000` 暂缺并标红；`L01b` 给了五项分（内容 2/2·形式 2/2·语法 1.5/2·拼写 1/2·词汇 1.4/2 = 7.9/10）与你的概述彩批（foundamental→fundamental、goverments→governments、desicions→decisions 三处拼写错误标粉色；"how" 一词标蓝色删除线，应删去）。
- **MCM-L（Q2）**：本题满分是 **3**（非常见的 2），三个正确项 A/C/D 你全选错成 E，得 0/3。
- **FIB-L（打字题，无选项）**：Q3/Q5 几乎全错（多为听错词/拼写：compacting/ministrate/curve、races/invest/yiels），Q4 四空全对。
- **MCS-L / SMW**：MCS-L(Q6) 选对得满分；两道 SMW（Q7/Q8）都选错，均为 0/1。
- **HIW**：复盘图给 `答案: Pronounced words: …`（实际读音）+ 屏幕错词下划线 + 你点了哪几个。本套 Q9 应点 6 个你点中 5 个（漏 basswood）、Q10 应点 5 个全部点中（满分）、Q11 应点 5 个只点中 2 个。
- **WFD（4 题）**：配色为绿命中 / 红括号漏写 / 灰删除线多写听错，用 `\lhit/\womit/\wbad`，每题加 `\wfdlegend` 图例。失分主要来自漏词 + 把没听清的部分瞎写一通（如 Q15 的 "for from the high"）。
- 成品：`整理卷/听力/000_PTE模考3B_听力_整理卷.{tex,pdf}`（10 页）+ 根目录干净名 `整理卷/PTE模考3B_听力_整理卷.pdf`。
