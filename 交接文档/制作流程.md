## 1. 环境安装（第一步，一次装好）

整套依赖三块：**XeLaTeX 引擎 + 中英字体**（排版）、**poppler**（把 PDF 渲成图自检）、**Pillow**（裁大图/放大读小字）。

> ⚠️ **以下是本仓库实测可用的完整命令**（root 下去掉 `sudo`）。只装 `texlive-xetex` 而漏了
> `texlive-latex-recommended`(fontspec/ragged2e)、`texlive-plain-generic`(ulem)、
> `texlive-lang-chinese`(xeCJK) 会编译失败——以下面为准。

```bash
# ① LaTeX 引擎 + 宏包
apt-get update
apt-get install -y \
  texlive-xetex texlive-latex-recommended texlive-latex-extra \
  texlive-plain-generic texlive-lang-chinese \
  fonts-noto-cjk fonts-texgyre poppler-utils

# ② Python 读图依赖
pip3 install Pillow
```

**装完自检**（四行都要有输出）：

```bash
xelatex --version | head -1
fc-list | grep -iE "Noto (Sans|Serif) CJK SC|TeX Gyre Heros" | sort -u
pdftoppm -v 2>&1 | head -1
python3 -c "import PIL; print('Pillow', PIL.__version__)"
```

> 字体名在 `ptestyle.sty` 里**写死**（`\setmainfont{TeX Gyre Heros}`、`\setCJKmainfont{Noto Sans CJK SC}`）。
> 换环境先 `fc-list` 确认装上，否则编译报缺字体。
> 本套素材是**已逐题裁剪好的单张 PNG**（不是 PDF 题目卷），所以**不需要** `PyMuPDF`/`numpy`；
> 只有 `build/pngcrop.py`（裁图太高的补充图）用到 Pillow。

> 克隆 + 开分支：`git clone <仓库网址> && cd <目录> && git checkout -b <任务指定的分支>`（分支命名见 §9：**不要随机名，用英文含义 + 时间戳**）。

## 2. 三条铁律（最重要）

1. **截图没有文字层 → 必须用眼睛读。** `pdftotext`/文字提取基本没用；一切靠 `Read` 工具看图、放大、肉眼逐字誊录。
2. **一切以原图为准，人工对照誊录。** 分数、每个批改词、AI 中文建议、平台配色，都要和截图核对一致；拿不准就放大再看。**平台用了颜色，你就要复刻颜色**（别只写文字摘要）。
3. **成品版本化、旧版永不改。** 成品放唯一的 `整理卷/`，**每个 part 各自从 `000` 起** +1；纯文字版本单文件自包含，含图片版本做成子文件夹。

## 5. 通用流程（六步）

1. **读懂截图**：直接 `Read` `cropped_questions/<part>/` 对应的图（每张都已是单题，一般不用再裁）；若某张图很高需要放大看小字，用 `build/pngcrop.py` 按比例裁一小段。
2. **在 `build/paper/` 排版**：复用 `ptestyle.sty`（§7 工具箱）；封面 `cover.tex` 已按 3B 成绩改好（如需重新核对，成绩来源见 §3）。
3. **逐题誊录**：题干/原文/录音原文、范文、你的作答、逐项评分、彩色批改、AI 建议——**一字一句对照原图**。**每题加中文翻译**（`\zh{…}`）。具体要素见**对应分册**。
4. **编译 + 保真核对**：`cd build/paper && xelatex preview_<part>.tex`（跑两遍）→ 把成品渲成 PNG 和原图并排比对 → 改到一致。
5. **出版本**：`build/flatten.py` 展平到 `整理卷/`（§8），编译验证与 preview 一致。
6. **提交推送**（§9）。

## 7. 共享 LaTeX 工具箱（`ptestyle.sty`，别重写）

**批改 / 标注宏**

| 宏 | 含义 | 外观 |
|----|------|------|
| `\fix{原}{正}` | 修改 / 拼写 / 缺空格 | 红删除线 + 绿改正 |
| `\del{词}` | 应删除 | 蓝删除线 + "删" |
| `\ins{词}` | 应插入 | 紫色 + "∧插" |
| `\add{原}{正}` | **平台漏标、本卷补标** | 橙波浪线 + "补" |
| `\miss{词}` | 漏读 / 未作答（灰） | 灰删除线 |

**口语 AI 语音识别配色**（复刻平台逐词评测）

| 宏 | 含义 |
|----|------|
| `\sg{词}` `\sy{词}` `\sr{词}` | 绿=优 / 橙=良 / 红=差 |
| `\smiss{词}` | 漏读/未读准（红删除线） |
| `\pse` | 停顿（灰 `/`） |
| `\asrlegend` | 一行图例（优/良/差/停顿/漏读） |

**评分 / 翻译**

| 宏 | 含义 |
|----|------|
| `\sfull{x/y}` `\spart{x/y}` `\szero{x/y}` | 评分：满分绿 / 部分橙 / 零低红 |
| `\zh{中文}` | 中文翻译行（蓝"译" + 灰译文）——**每题都加** |

**结构件**

- `\ptesection{中文}{英文}{该项分}` 章节大标题；`\ptetask{中文}{英文}` 题型小节分隔；`\ptesub{小标题}`。
- 题块 `\begin{qblock}{标号·题型}{右上:得分/用时} … \end{qblock}`。
- 文本框：`promptbox`（题干/原文，灰）、`modelbox`（范文，绿）、`youbox`（你的作答，红）、`notebox`（注解，蓝）、`asrbox`（语音识别，白）。
- 评分表：`tabularx` + `\scorehead`（用法照抄 `sec_listening_body.tex`）。
- 阅读专用：`\rok{词}`(选对✓)、`\rno{你的}{答案}`(选错✗)、`\rblank{答案}`。
- 听力专用：`\hiw{屏幕错词}{实际读音}`；WFD `\lhit`(命中绿)/`\womit`(漏写红括号)/`\wbad`(多写/听错灰删除线) + `\wfdlegend`。**本套（3B）实测配色与 `\lhit/\womit/\wbad` 定义一致**（绿命中、红括号漏写、灰删除多写/听错），无需新增变体宏——但**下一套如果平台换了配色，先放大核对再选宏**，别想当然复用。
- 新增宏请加在 `ptestyle.sty`（只增不改既有定义，以免破坏旧版的展平副本）。

## A. 版本规则（复述，必须照做）

1. 一个版本 = 一对成品 `<序号>_PTE模考3B_<部分>_整理卷` 的 `.pdf` + `.tex`。
2. **版本化存档**按 part 分文件夹：`整理卷/{口语,写作,阅读,听力}/`。
3. **最终成品**（每 part 最新版 PDF）另复制一份到 `整理卷/` 根，干净名 `PTE模考3B_<部分>_整理卷.pdf`；根目录**只放这 4 个**。
4. **每个 part 各自从 `000` 起 +1**（三位数，互不干扰）。
5. **旧版本只读，永不修改/覆盖**；只新增下一个序号。
6. 纯文字版本 = 单文件自包含 `.tex`；含图片版本 = 子文件夹（tex+img/+pdf）。都用 `build/flatten.py`。
7. **逐题裁剪素材**统一在 `cropped_questions/`（只读）；未裁原图在 `original_screenshots/`（只读）；**交接文档**统一放 `交接文档/`。
