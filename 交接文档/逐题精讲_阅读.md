## 1. 输出格式（⚠️ 阅读最易踩的坑：对的空也要逐个讲）
**考生反复强调**：她分低、很多空"蒙对/语感对"，所以——
- **FIB / FIBD&D：每一空都讲，且每空的 4(或词库多个)选项逐个分析**：✅正确词(为什么对)+ ❌各干扰项**各自为什么错**（含词库里"根本没用上的干扰词"）。**每个英文词都带中文翻译**（考生可能根本不认识那个词）。
- **MCM/MCS：每个选项(A–F)都讲**为什么对/错，标出同义替换点和陷阱类型。
- **RO：逐相邻对讲**为什么这么接（首句独立无回指、this/these/those 回指、However/And 位置）。
- 每题结构：题号·题型·得分 → 题目/材料(带中文) → 逐空/逐项讲 → 解题思路 → ★错因+防错 → 🧠记忆点。多用表格与**加粗**。
- FIBD&D 讲完 5 题加「专属诊断」（错位统计 + 对比上套）。

## 2. 题型通法

**FIB 读写填空(下拉 4 选 1，只扣选错空) / FIBD&D 拖词(共享词库、有多余干扰词)** —— 三步铁律：
1. **先判词性 + 用 a/an 砍一半**（`an ___`→元音开头；`the+___+impaired`→副词；`be ___ by`→分词；`proper ___ shows`→名词；`These ___ damage`→动词；`stays ___`/`a dense ___`→名词；主干完整的空→副词如 underground）。
2. **形近/义近词逐个翻译再选**（3B 高频雷：persecute 迫害/execute 处决、undermine 破坏/undertake 承担、release 发布/relief 缓解、severe 严重/distinctive 独特；搭配：racial bias、a wealth of、driving force、concerned with、social sanctions）。
3. **选完把整句默读一遍**，不通就换（3B 的 feed up 一读就别扭）。
FIBD&D 额外：**词库有多余干扰词→不硬凑**；**同根/形近词按形式选**；⭐**填完通读查"两词放反/错位"**——这是考生 FIBD&D 的头号病根，也是 ROI 最高的一步。

**MCM-R 多选**：**绝对词(all/never/only/definitely)先怀疑**；警惕**与原文相反**的选项（3B Q7 的 not quantifiable vs 原文 quantify、half vs twice）；**正确项常是同义替换**(association=link、gustatory system=taste system、one in 100 照搬)；细节偷换(similar≠same、daily≠every two days)；**选全**(多选漏选都扣)。

**MCS-R 单选**：定位句 + 同义替换(faster→quickly) + 排除"绝对/歪曲/笼统/与原文相反"；选 false 题找"和原文相反 + 绝对词(all)"的那项(3B Q16 的 all…harsh edges)。考生此题型稳(2B、3B 都满分)。

**RO 段落重排**：①锁首句(独立、引入话题、**无回指**；下定义句天然像首句；含 this/these/it/such/the+已知名词/However/And 的不开头)②连接词定位(However 转折多在中后段/收尾、And 收尾)③**代词回指串链**(this/these/those/Others + 名词 → 接回前面出现该名词的句子)→通读确认。

## 3. 错因归类库
词性/冠词没用 / 形近义近词混淆 / 选完不回读 / **FIBD&D 两词放反·错位** / 用干扰词硬凑 / 空着不填 / 绝对化陷阱 / **选了与原文相反的项** / 没识别同义替换 / MCM 漏选 / RO 回指没接 / 固定搭配不熟(concerned with、a wealth of、span back、draw on)。
