## 1. 输出格式（每题都按这个）
对**每一题**输出（对的题也讲），一个 markdown H2 小节 `## Q<n> · <题型> #<ID> <标题> —— <得分> <✅/❌注>`，下面紧凑列表覆盖：
1. **题目/材料**：1–2 句说清考什么、录音讲了什么（复杂的给要点+中文）。
2. **正确答案/原句**：FIB-L/WFD 列出每空/全句；选择题给正确项和考生所选。
3. **逐空/逐词讲**：✅ 对的也讲「为什么对、干扰/易混在哪、原文定位句、同义替换」；❌ 错的标「你的→正确 + 错因」，**逐处**讲。
4. **解题思路/套路**（该题型通法）。
5. **★ 错因归类 + 防错清单（1–3 条可操作动作）+ 🧠 一句话记忆点**。
- 硬性要求：**FIB-L 每空、MCM/MCS/SMW 每个选项（含没选中的干扰项）、HIW 每个应点错词（含漏点的）、WFD 每个词**都要讲到，别只讲错的。风格：中文讲解、英文原文照引、多用**加粗**和表格、每题给 🧠 记忆点。**结论必须对应考生真实作答，别泛泛而谈。**
- HIW 讲完三题、WFD 讲完四题，各加一段「专属诊断」（点中/漏点统计 + 坏习惯 + 对比上套）。

## 2. 七大题型通法（讲解时的考点库）

**SST 概述口语**（5 维各 2 分=10）：50–70 词、一段、主旨句+2–3 支撑、模板开头（The lecture mainly discusses…）、**写完回读查拼写和单复数**。讲考生哪维弱——Kathy 两套都弱在 **Spelling/Vocabulary**。

**MCM-L 多选**：逐项找定位句，只选原文明确支持的；**多选/漏选都扣**（选对+1、选错−1、最低 0）。正确项通常 2–3 个，**别只勾 1 个**。三大干扰：①张冠李戴（把别处/别人信息安到本题对象）②无中生有③夸大偷换（尤其"看似合理的总结句/总原则"）。绝对词（all/never/only）先怀疑。

**MCS-L 单选**：**题问谁就听谁**（the woman believes…）；抓因果连接（because）后的定位句；**听到 But/However 必换说话人/观点**；用同义替换匹配（convenience→convenient）；态度词组 positive/optimistic/expectant/hopeful vs negative/skeptical/cautious/disdainful。

**FIB-L 听力填空（打字）**：① **先判词性**（并列 `A,B,___ and C`→名词；`to be ___ by`→过去分词；`the ___ rate`→名词；主语位→名词）② 顺语义预测 ③ **写真听到的音、不写脑补的**；长词拆音节 ④ **绝不重复/堆变体乱填**（重复=没听清）⑤ 学术高频词背拼写。

**SMW 选词**：①抓整段主旨→缺词必与主旨**同向**②**常是首尾呼应**（开头出现的主题词，结尾填回去）③三项/四项各代入句末读一遍选逻辑最通的④查搭配（描述人的词、与对举词的关系，如 evil ↔ good）。

**HIW 找错词**：屏幕词 vs 录音不符就点。两类都抓：①怪词/生僻词（好抓）②**词性/语义不通的真词 + 音近真词**（followed/important/anything/University 这类——难抓，是漏点高发）。**从第一个词盯到最后一个词**（首尾是漏点高发区）。点错扣分，但 Kathy 的问题是**漏点不是误点**→对她的建议是**大胆多点**，尤其"读着不通的真词"。

**WFD 听写整句**：性价比最高、争取拿满。① **逐词速记（首字母/缩写）别造句** ② 守住**首词+尾词+动词** ③ **每个位置只写一个词**（PTE 按"命中词/总词数"算，多写的错词稀释命中率→写变体碰运气反而扣分）④ 写完查语法通顺（不通=听错）。

## 3. 错因归类库（给错题贴标签用）
知识点不会 / 没听出同义替换 / 粗心看漏 / **听不清拼写错** / **词形不跟语法**（invest→investors、unemployed→unemployment）/ **音近误听**（compacting↔complicating、curve↔curb、races↔resisted）/ 逻辑连接判断错（But）/ **句首句尾失焦** / **不顺主旨/没做首尾呼应**（SMW）/ **MCM 只勾一个** / **WFD 堆变体碰运气**（concentrated concentrating / majority majors majorities）。
